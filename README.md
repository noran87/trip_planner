# ✈️ Trip Planner

A full-stack web application for planning a trip and keeping track of activities.

Users can enter their destination and travel dates, save their trip information, and add or delete activities. The data is stored in a SQLite database so it remains available after refreshing the page.

## Features

- Save a trip destination
- Save start and end dates
- Add activities
- Delete activities
- Load saved trip information and activities after refreshing

## Technologies

- HTML
- CSS
- JavaScript
- Python
- Flask
- SQLite

## What I Practiced

This project helped me practice connecting the different parts of a full-stack application:

- Manipulating the DOM with JavaScript
- Handling click events
- Sending requests with `fetch()`
- Sending and receiving JSON
- Creating Flask routes
- Connecting Flask to SQLite
- Using SQL to insert, select, and delete data
- Keeping the browser interface synchronized with the database
